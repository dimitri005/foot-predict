# Football Predictor

Ce projet implémente une base d'application de prédiction football en Python avec Streamlit.

## Structure

- `app.py` : application Streamlit principale
- `src/data/sample_data.py` : jeu de données synthétique de démonstration
- `src/features/feature_engineering.py` : calcul de features simples
- `src/models/predictor.py` : moteur de prédiction déterministe

## Installation

```bash
pip install -r requirements.txt
streamlit run app.py
```
